# ncm-tui

A TUI Netease Music client written in Rust.

## Install

```bash
curl -fsSL https://mahomaho-rize.com/ncm-tui/install.sh | sh
```

The origin only hosts `install.sh` and prebuilt archives. This repository is not deployed to the server.

Pin a version or install location with `NCM_TUI_VERSION=0.1.0` and `NCM_TUI_INSTALL_DIR=$HOME/.local/bin`.

## Current porting milestone

The Rust port now includes the NCM request kernel, a transparent local library, and
fine-grained download orchestration:

- WEAPI double AES-128-CBC encryption and raw RSA `encSecKey`
- Python `base64.encodebytes` wire compatibility
- EAPI MD5 signing, AES-128-ECB request encryption, and response decryption
- cookie-backed `reqwest` session
- pure request preparation separated from HTTP execution
- login-status, track-detail, playlist-detail, album-detail, and audio URL API specs
- fixed crypto vectors generated by the vendored Python implementation
- track, track-list, playlist, and album download sources
- all-tracks, one-based position-range, and explicit track-ID selection
- selectable audio quality and bounded concurrent streaming downloads
- batched metadata, audio URL, and existing-track lookups (500 IDs per request/query)
- automatic atomic file installation followed by incremental library updates

## Transparent local library

The application owns its SQLite index internally at
`<download directory>/.ncm-tui/library.sqlite3`. Its path and maintenance controls
are deliberately absent from configuration and the TUI. UI code only receives the
semantic `Library` and `Downloader` services.

Successful downloads update track and playlist/album membership records immediately.
Known files are reconciled at startup and during lookups, while lightweight SQLite
optimization runs automatically after every 32 successful downloads. Search uses an
FTS5 index; download de-duplication uses batched indexed queries rather than one query
per track.

Fine-grained requests are represented with `DownloadRequest`:

```rust,no_run
use ncm_tui::download::{
    AudioQuality, DownloadRequest, DownloadSource, TrackSelection,
};

let request = DownloadRequest {
    source: DownloadSource::Playlist(123_456),
    selection: TrackSelection::Positions(10..=20),
    quality: AudioQuality::Lossless,
    overwrite: false,
};
```

The same request can target one track, an explicit track list, or an album, and can
select tracks by source position or ID without exposing persistence details.

cargo test
```

cargo test --test live_api -- --ignored --nocapture
```
